## YUSUNN 是什么

YUSUNN 让你在自己拥有的电脑上运行 coding agents，再通过 Workspace 从浏览器里查看启动项、拉起会话并接手控制。只要那台机器保持联网，你就可以在任何地方继续推进任务。

- **YUSUNN Desktop**：运行在本地的 macOS 应用，复杂拉起本地进程，监控状态和基本的配置管理。
- **YUSUNN Workspace**：浏览器里的工作区，可以查看启动项，拉起会话，账户管理。

## 快速开始

### 第 1 步：安装 YUSUNN Desktop

先在 Mac 上安装桌面端，它会负责本地 daemon、状态页和配置同步。

### 第 2 步：登录 YUSUNN Workspace

在浏览器中打开 Workspace，登录或创建账号。

### 第 3 步：复制 YUSUNN Key

在 **Account** 里的 **Local connection** 区域复制你的 **YUSUNN Key**。

### 第 4 步：填回 Desktop

打开 **YUSUNN Desktop**，进入 **Config**，把 Key 粘贴到 **Reply Key**，然后点击 **Save & Refresh**。

### 第 5 步：等待启动项刷新

保存后，Desktop 会重新连接并自动刷新启动项列表。

### 第 6 步：进入或继续会话

回到 **Status** 页面，选择一个启动项，开始新会话或继续已有会话。

## 使用前准备

YUSUNN 负责协调现有 coding agent，所以在继续之前，请先准备至少一个你已经能正常使用的 CLI。

- Claude Code
- Codex
- OpenCode
